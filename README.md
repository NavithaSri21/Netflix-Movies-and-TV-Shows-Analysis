# 🎬 Netflix Content Insights | Power BI Dashboard

## 📌 Project Overview
This project focuses on analyzing Netflix Movies and TV Shows data to explore content distribution, genre trends, country-wise availability, ratings, and release patterns.

An interactive Power BI dashboard was developed to transform raw Netflix data into meaningful insights and support data-driven decision-making.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and data visualization
- **Microsoft Excel** – Dataset review and exploration
- **CSV Dataset** – Netflix Movies and TV Shows data

## 📊 Key Performance Indicators (KPIs)
- Total Titles
- Total Movies
- Total TV Shows
- Minimum Release Year

## 🔍 Key Analysis
- Movies vs TV Shows distribution
- Content distribution by country
- Most popular genres
- Ratings distribution
- Release year trends
- Netflix content overview

## 📈 Dashboard Highlights
- Interactive visuals for exploring Netflix content
- KPI cards for quick business insights
- Charts to compare Movies and TV Shows
- Country-wise and genre-wise analysis
- Clean and user-friendly dashboard layout
